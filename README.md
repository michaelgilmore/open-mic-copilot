# Open Mic Copilot

I am a solo amateur musician that plays at local open mics regularly. Create an application that organizes my song lists.  It should look good on a tablet or phone both in portrait and landscape. I should be able to enter a song with its artist, lyrics, chord progression, tempo, and notes. It should easy to change keys by half steps. It should have the ability to start/stop lyric scrolling and set the speed of the scrolling. This should have a login so I can share it with others and they will only see their own entries. I should be able to create multiple setlists with creation dates pulling songs from the database.
